# Quality gate notes

## React Compiler

The Vite React plugin runs the Rust `oxc-transform-react` compiler. Compiler diagnostics are build findings, even when Vite exits zero. Refactor compiler-unsafe render mutations. For a known incompatible library such as TanStack Virtual, keep the implementation in `react-compiler-excluded/` and keep the Vite `compiler.sources` filter limited to `src/`; do not disable compilation project-wide or add suppression rules that leave a compiler warning.

## React Activity

Exercise state retention, effect cleanup, close-tab unmounting, and refresh-tab remounting separately. Hidden Activity trees retain state and DOM but restart effects on reveal. A route match alone does not prove the Activity registry renders the page.

## Pure CSR

The production output must contain `index.html` and assets, with no server directory or `_shell.html`. Test unauthenticated redirects with empty Web Storage and admin-only routes with both demo roles. Test a direct nested URL against a server configured with SPA fallback; a successful in-app navigation alone does not prove production routing works.

## Generated routes

`routeTree.gen.ts` is generated by `@tanstack/router-plugin`. A clean checkout must succeed with `pnpm build` before `pnpm typecheck` when the generated file is absent, or the file must be committed by project policy. Do not hand-edit it.

`pnpm routes:check` verifies the 93 explicit admin leaf files, while `pnpm template:check` verifies that the distributable scaffold still matches the canonical app. Fix drift with the corresponding generate/sync command; do not weaken either check.

## Coverage and browser tests

`pnpm test:coverage` runs through the application Vitest config and enforces thresholds over the critical auth, persistence, preference, tab-command, and chart models. Playwright tests live under `tests/e2e`; run them with `pnpm test:e2e`, never through root Vitest discovery.
